## 📢 프로젝트 소개

“일상 속 작지만 건강한 소비, 오구텃밭이 함께합니다.”

오구텃밭은 로컬 농산물을 소비자와 직접 연결하는 감성 쇼핑몰입니다.  
중간 유통 없이 신선한 작물을 판매하여, 소비자에겐 신뢰를, 생산자에겐 공정한 수익을 제공합니다.

아기자기한 농장 스타일의 UI와 작물 성장 관찰 등을 통해  
단순한 쇼핑을 넘어 ‘농업의 재미와 가치’를 함께 전달합니다.

<br/>

## 🌿 프로젝트 개요
- **프로젝트 명:** 오구텃밭 (Ogu Farm)
- **개발 기간:** 2025.07 ~ 2025.08
- **목표:** 프론트엔드 기술 역량 향상 및 협업 기반의 실제 서비스 형태 웹사이트 개발

> ### 🌱 오구텃밭 기획의도
> 단순히 상품을 판매하는 데 그치지 않고,  
> 작물의 성장 과정을 지켜보면서 작물 재배 → 수확, 체험 → 판매 → 정산의 흐름까지  
> 사용자가 전반적인 농업 사이클을 직접 간접 체험할 수 있도록 설계했습니다.
>
> - 감성적인 UI/UX 기반의 쇼핑 경험 제공  
> - 농장 콘셉트 기반의 작물 재배 인터페이스  
> - 실제 데이터 기반의 판매, 정산 기능 포함
> - 체험, 학습, 거래가 융합된 신개념 농업 체험 플랫폼
